# Anime App (Angular)

Web app hecha con AngularJS para mostrar animes desde archivos JSON locales.

## Ejecutar

```bash
python -m http.server 8000
```

Luego abre:

- http://localhost:8000/angular-app/

## JSON

Puedes agregar más archivos en `angular-app/data/` y añadirlos en `angular-app/js/app.js` dentro de `vm.sources`.
